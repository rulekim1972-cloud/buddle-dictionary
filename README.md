# 버들 국어사전

3학년을 위한 디지털 국어사전입니다. 종이 사전처럼 넘기고, 색인과 옆면으로 찾고, 낱말을 읽어 줍니다.

## GitHub Pages에 올리기
이 폴더의 파일을 모두 새 저장소에 그대로 올리고, Settings → Pages에서 main 브랜치를 고르면 주소가 생깁니다.
선생님 메뉴의 문제 링크·QR은 GitHub Pages 주소에서 써야 아이들 태블릿에서 바로 열립니다.

## 출처와 라이선스
- 낱말 데이터(data/words.json): 국립국어원 「한국어기초사전」(CC BY-SA 2.0 KR), 「국어 기초 어휘 선정 및 어휘 등급화 목록」(공공누리 제1유형)을 김목동 「디지털 국어사전」(kimmokdong.github.io/dictionary)이 가공한 자료를 다시 골라 엮음. 이 데이터도 CC BY-SA 2.0 KR 조건을 따릅니다.
- 글꼴: Pretendard (SIL Open Font License, fonts/Pretendard-LICENSE.txt)
- QR 만들기: qrcode-generator (MIT, Kazuhiko Arase)
